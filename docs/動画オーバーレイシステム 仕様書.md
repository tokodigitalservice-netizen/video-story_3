# 動画オーバーレイシステム 仕様書

## 1. システム概要

本システムは動画再生中の指定タイミングでオーバーレイボタンを表示し、ユーザーに対して追加コンテンツや外部リンクへの誘導を行うインタラクティブ動画プレイヤーである。

オーバーレイ表示タイミングやボタン情報は外部JSON設定ファイルで管理し、Cloudflare Workers経由で取得する。

主な用途は以下を想定する。

- 商品紹介動画
- 動画サイネージ
- 店舗案内動画
- ストーリー型コンテンツ
- インタラクティブ広告

# 3. コンポーネント構成

## App

アプリケーション全体の起動管理を行う。

### 主な責務

- 設定ファイル名決定
- 設定JSON取得
- ローディング制御
- エラー制御
- 動画再開制御

---

## VideoPlayer

動画プレイヤー本体。

### 主な責務

- 動画ロード
- 動画再生
- 現在時刻管理
- オーバーレイ表示制御

---

## OverlayButtonGroup

表示対象のボタン群を描画する。

### 主な責務

- ボタン配置
- ボタンクリック処理
- モーダル通知

---

## EndedOverlay

動画終了時の画面表示。

### 主な責務

- 再生終了画面表示
- リプレイ制御

---

## useVideoOverlay

動画再生時間を監視し、表示対象オーバーレイを判定する。

---

## useVideoRect

動画の実表示領域を算出する。

object-fit: contain 使用時の黒帯補正を行う。

# 8. オーバーレイ表示処理

## 判定条件


# 15. 状態管理

| State | 型 | 内容 |
|---------|---------|---------|
| config | OverlayConfig \| null | 設定情報 |
| error | string \| null | エラー内容 |
| videoReady | boolean | 動画ロード完了 |
| currentTime | number | 現在再生時間 |
| overlays | Overlay[] | オーバーレイ情報 |

# 16. システムの特徴

本システムは単純な動画プレイヤーではなく、動画視聴中にユーザーへ選択肢を提示し、追加コンテンツや詳細情報へ誘導するインタラクティブ動画プラットフォームである。

主な特徴は以下の通り。

- JSONによる表示制御
- Cloudflare配信対応
- モーダル連携対応
- 動画停止／再開制御
- 複数ボタン対応
- レスポンシブ対応
- サイネージ用途対応
- ストーリー型動画対応
