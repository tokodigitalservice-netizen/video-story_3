# インタラクティブ動画プレイヤー 実装ガイド

---

## 1. システム概要

Reactで作られた動画プレイヤーを、親サイトへ組み込む方法は2通りある。

```
【モーダル構成】
親サイト（index.html）
  └─ video-modal（子）← iframeでReactプレイヤーを表示
       └─ detail-modal（孫）← postMessageで開く

【単独構成】
直接URL or <a>タグ or iframe埋め込み
  └─ Reactプレイヤー（子）
       └─ 別タブで孫プレイヤーを開く（_blank）
```

---

## 2. モーダル構成

親サイトにCSS・JS・HTMLスニペットを仕込んでモーダル表示する方法。

### 2-1. modal.css

```css
/* モーダル外枠 */
```

### 2-2. HTML スニペット

トリガーボタン（呼び出し側）:

```html
<!-- 呼び出しボタン例 -->
<div onclick="openDiagnosis('https://player.example.com/?config=/configs/main.json')"
     style="cursor: pointer;">
  動画を見る
</div>
```

モーダル本体（`</body>` の直前に配置）:

```html
<!-- モーダル①: メイン動画プレイヤー -->
<div id="video-modal" onclick="closeDiagnosis()">
  <button id="modal-close" onclick="closeDiagnosis()">✕</button>
  <div class="loader-wrapper" id="loader-wrapper">
    <div class="spinner"></div>
  </div>
  <iframe
    id="diag-frame"
    src=""
    style="width:100%; height:100%; border:none; background:black;"
    onclick="event.stopPropagation()"
  ></iframe>
</div>

<!-- モーダル②: 孫動画（postMessageで開く） -->
<div id="detail-modal" onclick="closeDetailModal()">
  <button id="detail-close" onclick="closeDetailModal()">✕</button>
  <div class="loader-wrapper" id="detail-loader-wrapper">
    <div class="spinner"></div>
  </div>
  <iframe
    id="detail-frame"
    src=""
    style="width:100%; height:100%; border:none; background:black;"
    onclick="event.stopPropagation()"
  ></iframe>
</div>
```

### 2-3. script.js

```javascript
// ── モーダル①（メイン動画プレイヤー）
function openDiagnosis(url) {
  const modal  = document.getElementById('video-modal');
  const frame  = document.getElementById('diag-frame');
  const loader = document.getElementById('loader-wrapper');

  loader.style.display = 'flex';
  frame.src = url;
  modal.classList.add('open');
  document.body.style.overflow = 'hidden';

  frame.onload = () => { loader.style.display = 'none'; };
  setTimeout(() => { loader.style.display = 'none'; }, 3000);
}

function closeDiagnosis() {
  const modal = document.getElementById('video-modal');
  const frame = document.getElementById('diag-frame');

  modal.classList.remove('open');
  frame.src = '';
  document.body.style.overflow = 'auto';
}

document.getElementById('diag-frame')
  .addEventListener('click', e => e.stopPropagation());


// ── モーダル②（孫動画）
function openDetailModal(configUrl) {
  const modal     = document.getElementById('detail-modal');
  const frame     = document.getElementById('detail-frame');
  const mainFrame = document.getElementById('diag-frame');
  const loader    = document.getElementById('detail-loader-wrapper');

  loader.style.display = 'flex';
  frame.src = `https://player.example.com/?config=${encodeURIComponent(configUrl)}`;
  modal.classList.add('open');
  document.body.style.overflow = 'hidden';

  frame.onload = () => { loader.style.display = 'none'; };
  setTimeout(() => { loader.style.display = 'none'; }, 3000);

  mainFrame.contentWindow?.postMessage({ type: 'pause' }, '*');
}

function closeDetailModal() {
  const modal     = document.getElementById('detail-modal');
  const frame     = document.getElementById('detail-frame');
  const mainFrame = document.getElementById('diag-frame');

  modal.classList.remove('open');
  frame.src = '';
  document.body.style.overflow = 'auto';

  mainFrame.contentWindow?.postMessage({ type: 'resume' }, '*');
}

document.getElementById('detail-frame')
  .addEventListener('click', e => e.stopPropagation());


// ── postMessage 受信（Reactプレイヤーからの通知）
window.addEventListener('message', (e) => {
  // 本番では自ドメインに限定する
  // if (e.origin !== 'https://your-domain.com') return;

  const data = e.data;
  if (!data || typeof data !== 'object') return;

  switch (data.type) {
    case 'open-detail-modal':
      if (data.config) openDetailModal(data.config);
      break;
    case 'close-self':
      closeDetailModal();
      break;
  }
});
```

### 2-4. JSON設定（モーダル構成）

```json
{
  "id": "btn-example",
  "type": "modal",
  "modalConfig": "/configs/sub.json",
  "showAt": 9,
  "hideAt": 19,
  "position": { "top": 74, "left": 35 },
  "style": { ... }
}
```

- `type: "modal"` + `modalConfig` あり → postMessageで孫モーダルを開く
- `type: "modal"` + `modalConfig` なし → **無反応になるので必ず設定すること**

## 3. 単独構成

親サイトへの組み込みなし。ReactプレイヤーのURLを直接開く、またはリンクを貼る方法。

### 3-1. 呼び出し方

```html
<!-- 別タブで開く -->
<a href="https://player.example.com/?config=/configs/main.json" target="_blank">
  動画を見る
</a>

<!-- 同タブで開く -->
<a href="https://player.example.com/?config=/configs/main.json">
  動画を見る
</a>

<!-- ページ内に埋め込む -->
<iframe
  src="https://player.example.com/?config=/configs/main.json"
  style="width:100%; aspect-ratio:16/9; border:none;"
></iframe>
```

### 3-2. JSON設定（単独構成）

孫動画を別タブで開く場合:

```json
{
  "id": "btn-example",
  "type": "link",
  "href": "https://player.example.com/?config=/configs/sub.json",
  "target": "_blank",
  "showAt": 9,
  "hideAt": 19,
  "position": { "top": 74, "left": 35 },
  "style": { ... }
}
```

外部サイトへ飛ばす場合:

```json
{
  "type": "link",
  "href": "https://example.com",
  "target": "_blank"
}
```

同タブ遷移（戻るボタンで戻れる）:

```json
{
  "type": "link",
  "href": "https://example.com",
  "target": "_self"
}
```

- `type: "modal"` は**使用しない**（postMessageを受け取る親がいないため）
- **すべて `type: "link"` で統一する**

---

## 4. モーダル構成 vs 単独構成 比較

| 項目 | モーダル構成 | 単独構成 |
|---|---|---|
| 必要なファイル | modal.css + script.js + HTMLスニペット + JSON | JSONのみ |
| 孫動画の呼び出し | postMessage → 孫モーダルをオーバーレイ表示 | `_blank` で別タブ or `_self` で同タブ遷移 |
| 孫動画を閉じる | ✕ボタンで閉じると元動画に戻る | タブを閉じる or 戻るボタン |
| 元動画の再生状態 | 孫を開く時に一時停止、閉じると再開 | 別タブなので元動画はそのまま継続 |
| ユーザー体験 | 没入感が高い | シンプル・軽量 |
| 実装の複雑さ | 高い | 低い |
| JSONの `type` | `"modal"`（`modalConfig` 必須） | `"link"`（`href` 必須） |

---

## 5. 注意事項

- 本番環境では `postMessage` の受信元を自ドメインに限定する
  ```javascript
  if (e.origin !== 'https://your-domain.com') return;
  ```
- `openDetailModal` 内のプレイヤーURLは本番URLに差し替える
- モーダル構成で `type: "modal"` を使う場合は `modalConfig` を必ず設定する（未設定だと無反応）
